Menu e fluxo de dados

main.c controla as operações e mantém os objetos locais. Os módulos se comunicam por parâmetros e retornos; não há variáveis globais.

Texto → vetor → mergesort → relatório + índice

Índice reaberto → busca binária → offset → linha

Após validação inicial, a consulta custa O(log n + k), para k resultados. Os limites são inclusivos.

Inteiros little-endian. Total: 32 + 16 × n bytes.

fseek(indice, 32 + 16 * i, SEEK_SET)
O evento permanece no arquivo-texto original.

Por que recursão?

Dividir o vetor ao meio, ordenar as duas metades e intercalar. Caso base: zero ou um registro. A estrutura das chamadas acompanha a divisão do problema.

Vetor auxiliar O(n) · pilha O(log n). Em empates, a metade esquerda vem primeiro.

Demonstração e robustez

Exemplo: 8 registros · INFO 4 · ERROR 2 · WARN 2.
Evento líder: Login realizado, 3 ocorrências.
Consulta exata às 09:30:00: 2 registros.

Datas e linhas inválidas são tratadas. Índice incompatível é recusado. Após alterar o log, reconstrua o índice; mantenha a origem intacta durante a sessão.
